# Published assessor guidance lookup

Grant source review now also checks the reviewed page for assessor/scoring links. If none are found, it runs a bounded OpenAI web search for the grant name and official source domain. Innovate UK domains are explicitly related (UKRI, Business Connect and Innovation Funding Service). Different IFS competition IDs and unrelated domains are rejected. Redirect destinations are rechecked. This does not claim exhaustive web coverage or silently apply a framework from another round.

The source fetcher uses public IPv4 DNS pinning, HTTPS-only URLs, limited redirects, byte caps and network timeouts. Only the assessor path opts into PDF parsing (5 MB, 80 pages, 120,000 extracted characters). Scans, oversized or unreadable PDFs remain manual checks. The original HTML-only eligibility/website readers retain their existing behavior. PDF parsing uses the library's core entry point to avoid its executable sample-file behavior.

At most three pages/documents (including the root if it mentions assessment guidance) are read. Each retained source has a content hash, applicability label and lookup timestamp. Search-discovered documents are candidate references only; their text is not sent as an applicable rubric to drafting. Directly linked documents and guidance on the original page can supply explicit assessment expectations. The labels indicate source linkage, not independent confirmation that the document is the latest or that every rubric was read. Applicant-visible warnings preserve failed searches, unreadable links, review limits and missing structured criteria.

Structured rows require verbatim source excerpts. Expectations, question labels and any stated bands/weights remain AI-extracted and require source review. No applicant assessor score, funding probability or eligibility changes are calculated. Existing eligibility and workload extraction remain separate. Founder Pack and Question Assistant receive the verified excerpts, source references and limitations through the shared reviewed-grant context. Older saved reviews remain readable and show that assessor lookup has not yet run; users run source review again to populate it. No new database table or migration is required.

Tests: scripts/test-assessor-framework.ts plus criteria extraction, source-context, website-refresh and eligibility regression checks. A live fetch of IFS competition 2584 found download 30742 and extracted 27,151 characters of its Frontier AI Phase 1 assessor guidance. Live authenticated persistence and OpenAI search/extraction still require deployment validation.

## Default preparation framework

When no structured applicable assessor entries are verified (including older or failed reviews), the source-review UI and grant drafting use GrantsCopilot default preparation framework v1. It covers need/project fit, approach, demand/evidence, impact, delivery, costs and risks. It is an editorial checklist, not an official Innovate UK rubric. It defines no scores, weights, thresholds or extra eligibility conditions. Applicable published questions, word limits and competition-specific criteria take precedence. Source lookup status remains visible, so an incomplete search is not recast as proof that no framework exists. Verified published assessor entries replace the default rather than being blended into an invented official rubric. Start Up Loans scheme requests opt out of the no-document grant fallback. Tests are in scripts/test-default-grant-framework.ts.
